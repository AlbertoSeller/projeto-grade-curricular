# Grade Curricular Interativa - Sistemas de Informação

## 📘 Descrição do Projeto

Este projeto apresenta uma interface web interativa para visualização da grade curricular do curso de **Sistemas de Informação**. A aplicação permite filtrar as disciplinas por semestre, facilitando a consulta e promovendo uma navegação mais clara e acessível quando comparada aos tradicionais arquivos PDF.

---

## 🎯 Objetivos

* Apresentar a matriz curricular de forma organizada e responsiva.
* Facilitar a identificação de disciplinas por semestre.
* Indicar claramente carga horária e modalidade (Presencial/EAD).
* Melhorar a usabilidade e acessibilidade para diferentes perfis de usuários.

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia          | Função                                 |

| **Bootstrap 5**     | Estilização e responsividade           |
| **CSS Customizado** | Ajustes visuais e refinamento estético |
| **JavaScript**      | Filtragem dinâmica por semestre        |

---

## 🔧 Como Executar

1. Baixe ou clone os arquivos do projeto.
2. Abra o arquivo **index.html** em um navegador (Chrome, Edge, Firefox, etc.).
3. A interface estará disponível imediatamente, sem necessidade de instalação.

## ♿ Acessibilidade

O projeto inclui melhorias de acessibilidade, como:

* `aria-label` no seletor de semestres
* Destaque de foco visível para navegação via teclado
* Suporte automático a modo de alto contraste quando ativado no sistema operacional
